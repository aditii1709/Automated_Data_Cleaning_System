Automated Data Cleaning and Reporting System

About

A Python-based project that automates data cleaning and preprocessing using a synthetic employee dataset containing 500 original records.

The project identifies and handles missing values, duplicate records, inconsistent formatting and invalid data.

Technologies Used

1.Python
2.Pandas
3.NumPy
4.Matplotlib
5.Seaborn
6.Jupyter Notebook

Key Features

1.Missing value detection and handling
2.Duplicate record removal
3.Text standardisation
4.Data type correction
5.Invalid value handling
6.Automated data-quality reports
7.Data visualisation

Project Outputs

1.Cleaned employee dataset (CSV)
2.Before-and-after quality reports
3.Automated summary report
4.Data visualisation charts
